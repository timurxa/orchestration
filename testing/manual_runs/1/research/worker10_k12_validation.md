## Method

The driver calls the unchanged public API with
`dht_plan_create_profile_ex(N, 1e-13, 12, 18.0, 1, 4)`. MPFR precision is 400
bits, or approximately 120.4 decimal digits. The reference computes
`J0(2*pi*m*k/N)` with `mpfr_j0`, accumulates each real and imaginary output at
400-bit precision, and rounds only the final reference output to binary64.

The independent high-precision asymptotic evaluator uses

```text
A12(z) = sqrt(2/(pi*z)) * sum(q=0..11)
        c_q * (-1)^floor(q/2) * T_q(z-pi/4) / z^q
c_0 = 1,  c_(q+1) = c_q*(2q+1)^2/(8*(q+1))
T_q = cos for even q, sin for odd q
```

For ratio 4, the first nonempty asymptotic block is `m=4..15`. For target row
`m=4`, the transition is
`n0 = ceil(18*N/(2*pi*4))`, matching the implementation's block rule. The
adversarial input is generated entirely in MPFR:

```text
x[k] = 0                                      for k < n0
x[k] = sign(A12(2*pi*4*k/N)-J0(2*pi*4*k/N)) * (1 - 0.375 i)  for k >= n0
```

Thus the scalar asymptotic residuals add with the same sign in the target row.
There were no zero residual signs. Small cases use full MPFR vectors at
`N=64,128,256,512`. Large checkpoints are `N=1024,2048,4096,8192,16384,32768,65536`.
For large non-delta cases, references use the deterministic selected rows

```text
unique({0,1,3,4,15,16,63,64,255,256,1023,1024,4095,4096,
        16383,16384,32768,N/2,N-1} intersect [0,N-1]).
```

The large delta cases use full-vector MPFR references. `LARGE_ROWS` gate labels
below apply only to the selected rows; they are not full-vector certification.
