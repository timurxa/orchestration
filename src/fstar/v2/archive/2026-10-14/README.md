# F* v2 archived design drafts — 2026-10-14

These files preserve the complete package-owned draft and work DAG that were
active before the top-down system specification was written. They remain
available as design evidence, including detailed codec proposals, source
links, P0–P16 obligations, open decisions, and the retired execution DAG.

They are no longer active authorities. The current intention and theorem
order are in [the system specification](../../theory/system_spec.md); current work
status is in [the work DAG](../../state/work_dag.md). In case of conflict,
the system specification controls. Nothing in this archive is claimed to be
implemented or proved.
