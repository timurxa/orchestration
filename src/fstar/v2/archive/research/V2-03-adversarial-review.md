## Least-complex viable architecture

1. Retain first-order `GraphDesc` and structural syntax codec. Parser then typed resolver is smaller than folding registry lookups into parser: malformed syntax rejected before type work; codec independent of manifest; graph bytes remain portable. Keep exact re-encode guard; prove round-trip from structural parser inverse and canonicality from guard. Component-codec composition is viable only if every constructor field has stable codec composition laws; it adds a second layer of identity/EOF/canonicality obligations and does not solve typed reconstruction.
2. Make manifest a closed finite, proof-carrying registry. Entries package exact `Work`, plain/indexed codecs, pair-family codecs, schema tokens, and membership/coherence. Tokens denote carrier types; manifest construction proves equal token identity means equal carrier. Derive work input/output schema from codecs in exact work package. Keep implementation identity distinct from schema identity. This combines schema-token transport with exact existential package; token-only lookup cannot select executable code, package-only lookup cannot equate hidden types.
3. Replace assumed port telescope with concrete dependent snoc/vector context, storing each exact prior typed output and schema token. `resolve_graph` traverses nodes in encoded order; lookup exact work package; recursively resolve wire: root, prior port, canonical plain/indexed constant, pair (resolve family at exact environment and left value, then right), projections. Reject missing/non-prior/mismatched entries. Check final output family `o x`; return original descriptor plus `typed_graph_witness` and membership evidence. Derive `graph_wf` from that result. Same path for decoded root/generated bytes.
4. Generator admission: keep raw pure `GeneratorRef`, but require pinned `GeneratorMember` proof whose result carries descriptor, successful `resolve_graph` witness, and plan proof for every input/allocation. Prove callback is exact registry entry via membership. Runner gets allocation only from replayed ledger; keep that state-derived premise outside pure graph theorem. Use example input count with exact per-node allocations; prove keys `0..n-1`, prior edges, output index, ordered plan, `graph_wf`, then admission. Do not runtime-test universal property; it is static theorem.

## Alternatives weighed

- **Structural AST codec vs component codec composition:** retain AST. Current fixed grammar, declared lengths, EOF, and equality guard make accepted bytes exact with one top-level proof. Composition could reuse codecs but multiplies nested law dependencies and still parses only syntax.
- **Decode-then-resolve vs typed registry decode:** decode-then-resolve wins. It separates canonical syntax from manifest-dependent types. Direct typed decode duplicates parser and registry branching, while hidden-index transport remains same theorem.
- **Parser inverse vs constructor codec laws:** prove parser inverse for constructor round-trip; use executable re-encode equality for accepted-byte canonicality. Equality guard avoids proving parser injectivity/canonical grammar uniqueness. Alternative canonical constructor laws alone do not establish decoder's rejection behavior.
- **Generator proof evidence vs checked result package:** static universal admission evidence is least complexity for pure F* callback. Runtime `checked_generated_graph` alone checks one result, cannot establish pinned generator admission for every input/allocation unless run at every invocation and still bind generator identity. Pair admission proof with runtime result resolver for defensive construction; no second serialized proof object.

## Dependencies and caveats

Codec theorems depend on natural-list bytes, total list recursion, parser/encoder equations, and `input == encode parsed`; they do not depend on codec laws or registry. Resolver soundness depends on exact manifest binding, registry uniqueness, token coherence, codec roundtrip/canonical laws, concrete prior-port lookup, and recursive `PairWire` typing. `graph_wf` additionally depends on unique keys, exact ordered node traversal, prior references, node/output types, and exact work/codec/family membership. Generator admission depends on resolver soundness, allocation-plan traversal aligned one-for-one to node order, exact `maximum_charge`, positive nested fuel, and universal callback proof. Pinned manifest identity/content binding remains P0 open (`implementation_spec.md:107-116`); static registry cannot represent arbitrary runtime-open F* types/families (`V2-03-resolver-options.md:59`).
